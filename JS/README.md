# JavaScript Classes for Full Stack Web Development

This directory is structured into **two dedicated learning sections** designed to take a complete beginner to professional Full Stack proficiency:

```
JS/
│
├── 1. Core_JS/           # Section 1: Pure JavaScript (No HTML/CSS)
│   ├── Class-1.js        # Introduction to JS & Console Output
│   ├── Class-2.js        # Variables & Data Types
│   ├── Class-3.js        # Operators & Expressions
│   ├── Class-4.js        # Conditional Statements
│   ├── Class-5.js        # Loops & Iteration
│   ├── Class-6.js        # Functions in JavaScript
│   ├── Class-7.js        # Strings & String Methods
│   ├── Class-8.js        # Arrays & Basic Operations
│   ├── Class-9.js        # Array Higher-Order Methods (Essential for React!)
│   ├── Class-10.js       # Objects & Object Manipulation
│   ├── Class-11.js       # Modern ES6+ Features
│   ├── Class-12.js       # Scope, Closures & Hoisting
│   ├── Class-13.js       # Asynchronous JS & Timers
│   ├── Class-14.js       # Promises in JavaScript
│   ├── Class-15.js       # Async/Await & REST API Data Handling
│   └── README.md
│
└── 2. DOM_JS/            # Section 2: Browser & DOM Manipulation (Interactive HTML)
    ├── Class-1.html      # Intro to DOM & Element Selectors
    ├── Class-2.html      # Modifying Element Content
    ├── Class-3.html      # Modifying Attributes & Properties
    ├── Class-4.html      # Modifying Styles & ClassList
    ├── Class-5.html      # Creating & Appending Elements
    ├── Class-6.html      # Mouse Events & addEventListener
    ├── Class-7.html      # Keyboard & Input Events
    ├── Class-8.html      # Form Handling & Validation
    ├── Class-9.html      # Event Bubbling & Delegation
    ├── Class-10.html     # BOM & Web Storage (localStorage)
    ├── Class-11.html     # Timers in DOM (Digital Stopwatch)
    ├── Class-12.html     # Dynamic Todo App (CRUD Operations)
    ├── Class-13.html     # Fetch API & Dynamic UI Cards
    ├── Class-14.html     # Modal Popup & Overlay Component
    ├── Class-15.html     # Mini Project: Search & Filter Dashboard
    └── README.md
```

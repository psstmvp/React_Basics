# Section 2: DOM JavaScript (Browser & DOM Manipulation)

This section teaches how JavaScript interacts with HTML elements in the Document Object Model (DOM) using **pure HTML and JavaScript (without any CSS)**, allowing complete beginners to focus 100% on DOM methods and event logic.

---

## 🚀 How to Run Any Class

Simply **double-click** any `.html` file to open and test it directly in your web browser (Google Chrome, Microsoft Edge, Firefox, Brave, etc.).

---

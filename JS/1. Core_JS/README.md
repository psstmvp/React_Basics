# Section 1: Core JavaScript (Without HTML & CSS)

This section teaches the foundational programming concepts of JavaScript in pure `.js` files, designed to run directly using Node.js without needing any HTML or CSS files.

---

## 🚀 How to Run Any Class

Open your terminal, navigate to this directory:
```bash
cd "d:\akash\React_Basics\JS\1. Core_JS"
```

Run any class file directly using Node.js:
```bash
node Class-1.js
node Class-2.js
...
node Class-15.js
```

## 📚 Curriculum Roadmap

| Class | Topic | Key Concepts Covered |
| :--- | :--- | :--- |
| **Class-1.js** | Introduction & Console Output | Comments, `console.log`, `console.warn`, `console.error`, `console.table` |
| **Class-2.js** | Variables & Data Types | `var`, `let`, `const`, Primitives (string, number, boolean, null, undefined, bigint, symbol), `typeof` |
| **Class-3.js** | Operators & Expressions | Arithmetic, Assignment, Strict Equality `===` vs `==`, Logical `&&` `\|\|` `!`, Ternary Operator |
| **Class-4.js** | Conditional Statements | `if`, `else if`, `else`, `switch` statements, Truthy and Falsy values |
| **Class-5.js** | Loops & Iteration | `for`, `while`, `do-while`, `break`, `continue`, `for...of`, `for...in` |
| **Class-6.js** | Functions | Declarations, Expressions, Arrow Functions `=>`, Default Parameters, Callbacks |
| **Class-7.js** | Strings & String Methods | Template Literals (`` `${}` ``), `.trim()`, `.toLowerCase()`, `.includes()`, `.slice()`, `.split()` |
| **Class-8.js** | Arrays & Basic Operations | Indexing, `.push()`, `.pop()`, `.shift()`, `.unshift()`, `.slice()` vs `.splice()`, Immutability |
| **Class-9.js** | Array Higher-Order Methods | `.forEach()`, `.map()`, `.filter()`, `.find()`, `.reduce()`, `.some()`, `.every()` (Essential for React!) |
| **Class-10.js** | Objects & Manipulation | Object literals, dot vs bracket notation, `this` keyword, `Object.keys()`, `Object.values()` |
| **Class-11.js** | Modern ES6+ Features | Destructuring (Arrays & Objects), Spread `...`, Rest `...`, Optional Chaining `?.`, Nullish Coalescing `??` |
| **Class-12.js** | Scope, Closures & Hoisting | Global, Function & Block Scope, Closures, Encapsulation, Hoisting, Temporal Dead Zone |
| **Class-13.js** | Asynchronous JS & Timers | Synchronous vs Asynchronous, Event Loop, `setTimeout()`, `setInterval()`, Callback Hell |
| **Class-14.js** | Promises | Promise states, `resolve()`, `reject()`, `.then()`, `.catch()`, `.finally()`, `Promise.all()` |
| **Class-15.js** | Async / Await & API Handling | `async`, `await`, `try...catch`, REST API simulation, Error handling |
